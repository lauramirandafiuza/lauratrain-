# Laura Train v4

## Atualização no GitHub
Substitua os arquivos da raiz do repositório por estes arquivos e faça commit.
O histórico local é migrado automaticamente da v3 para a v4 quando o app abre no mesmo endereço.

## Antes de atualizar
Abra a versão atual no iPhone e faça um backup em Coach → Exportar JSON.

## O que mudou
- quadro binário dos últimos 30 dias
- meta semanal de 5 treinos/dias ativos
- corrida avulsa conta como dia ativo
- Meus Treinos na página Hoje, com consulta da última performance
- mensagem diária
- animação de conclusão
- PR de carga e PR de repetições
- séries de aquecimento
- opção de pular exercício
- edição de treinos concluídos
